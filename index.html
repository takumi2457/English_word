音声の自動選択について

以前のコードは、端末にある英語(en-US)の音声のうち、リストの最初に出てくるものを使っていました。そのため端末によっては、機械的な声や古い声が選ばれることがありました。

今のコードは、端末内の英語音声に点数をつけて、自然なもの（Samantha、Google US English、「Enhanced」「Premium」「Natural」と付くもの）を優先します。Macにある変な声（Fred、Zarvoxなど）は選ばれにくくしています。

ただし、選べるのはその端末に入っている音声だけです。良い音声が1つも入っていない端末では、自動にしても変わりません。その場合は、前回の回答でお伝えした方法で音声を追加すると改善します（iPhoneは「設定→アクセシビリティ→読み上げコンテンツ→声→英語」）。

自分のスマホでの確認は、アプリの「管理」画面にある「発音の設定」で、声を選んで「この音声で試し聞き」を押すとできます。

アプリにする手順（最初から順番に）

パソコンで作業するのが一番簡単です。

パート1：GitHubにアカウントを作る

  1. ブラウザで github.com を開き、「Sign up」を押します。
  2. メールアドレス、パスワード、ユーザー名を入力します。ユーザー名は公開URLの一部になるので、英数字で決めてください（例：taro123）。
  3. メールに届く認証コードを入力して登録を完了します。

パート2：置き場所（リポジトリ）を作る

  1. 画面右上の「＋」→「New repository」を押します。
  2. 「Repository name」に tango と入力します（半角小文字がおすすめです）。
  3. 「Public」を選びます（無料で公開するには必須です）。
  4. 他の項目はそのままで、「Create repository」を押します。

パート3：ファイルをアップロードする

  1. 作成後の画面にある「uploading an existing file」というリンクを押します。
  2. 6つのファイル（index.html、manifest.json、sw.js、icon-192.png、icon-512.png、apple-touch-icon.png）を、フォルダに入れずに枠へドラッグ＆ドロップします。
  3. 6つ全部が表示されたことを確認して、下までスクロールし、緑の「Commit changes」を押します。

パート4：公開する

  1. リポジトリの上のほうにある「Settings」タブを開きます。
  2. 左のメニューから「Pages」を選びます。
  3. 「Build and deployment」の「Source」が「Deploy from a branch」になっていることを確認します。
  4. 「Branch」を main、フォルダを / (root) にして「Save」を押します。
  5. 1〜2分待ってからページを再読み込みすると、上のほうに「Your site is live at https://ユーザー名.github.io/tango/」と表示されます。これが単語帳のURLです。

このURLをブラウザで開いて、単語帳が表示されれば成功です。

パート5：スマホにアプリとして入れる

iPhone（Safariで作業）

  1. Safariで、上のURLを開きます。
  2. 画面下の共有ボタン（四角から上向きの矢印が出ているマーク）を押します。
  3. 下にスクロールして「ホーム画面に追加」を選びます。
  4. 名前を確認して「追加」を押します。「Webアプリとして開く」というスイッチが出たら、オンのままにします。

Android（Chromeで作業）

  1. Chromeで、上のURLを開きます。
  2. 右上の「⋮」を押します。
  3. 「アプリをインストール」（または「ホーム画面に追加」）を選び、「インストール」を押します。

パソコン（Chrome / Edge）
アドレスバーの右端に出る「インストール」アイコンを押します。

パート6：単語を入れて使う

重要：iPhoneでは、Safariで開いた状態と、ホーム画面のアイコンから開いた状態で、保存データが別々になります。 単語の読み込みは、必ずホーム画面のアイコンから起動してから行ってください。

  1. アイコンからアプリを起動し、「管理」タブを開きます。
  2. 「Excel／CSVを読み込み」でファイルを選びます。ファイルはiCloud Driveなど、スマホから選べる場所に置いておいてください。
  3. 読み込むシートにチェックを入れて、「選んだシートを読み込む」を押します。
  4. 「学習」タブに戻れば、使い始められます。

更新するとき

単語帳アプリを修正したときは、GitHubのリポジトリを開き、「Add file」→「Upload files」から同じファイル名でアップロードして「Commit changes」を押します。1〜2分後に反映されます。反映されない場合は、アプリを一度閉じて開き直してください。

知っておいてほしいこと

  • 記録は端末ごとに別々です。機種変更やブラウザのデータ消去で消えるので、ときどき「記録を書き出す」でCSVを保存しておくと安心です。
  • 他の人に使ってもらうには、URLを送るだけです。その人は自分のExcelを読み込んで使います。あなたの単語は見えません。
  • Excelは、1列目＝単語、2列目＝意味で作ります。品詞・例文・例文訳は3〜5列目に入れられます。「覚えた」「読み方」「発音記号」は、1行目にその名前を書いた列を作れば、どの列に置いても読み込まれます。

途中でつまずいた画面があれば、どの手順で何が表示されたか教えてください。そこから一緒に確認します。

音声ツールの導入手順を整理中

どちらか一方ではなく、役割を分けて両方使うのが一番うまくいきます。

おすすめの進め方

1. 端末には、良い音声を1つだけ入れる
端末に全部入れる必要はありません。入れすぎても容量を使うだけで、アプリが使うのは選んだ1つだけです。自然な英語音声（iPhoneなら「Samantha」の Enhanced など）を1つ入れて、アプリの「発音の設定」で選べば十分です。これだけで、読み上げの大半は自然になります。

2. それでもおかしい単語だけ、Excelの「読み方」列で直す
音声を良くしても、read（過去形）や lead、live のように、綴りが同じで読み方が違う単語は間違えやすいままです。こうした単語はExcelにメモしておくのが確実です。ご提案の「Excelを作る段階で正しい発音をメモしておく」はこの使い方で、とても良い考えだと思います。

3. 修正の仕組みを分ける理由

  • 音声の追加は端末ごとの設定なので、他の人に使ってもらう場合、相手の端末は直りません。
  • Excelの「読み方」はファイルに入っているので、誰が使っても同じように直ります。

つまり、自分用の改善は端末の音声、みんなに効く改善はExcelという分担です。

端末に入れる音声は1つだけで十分です。全部入れる必要はありません。端末ごとのやり方をまとめます。

iPhone / iPad（一番手軽）

  1. 「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」を開きます。
  2. 「英語」を選ぶと声の一覧が出ます。ダウンロードのマークがある声は、まだ入っていないものです。声の名前をタップすると試し聞きができ、ダウンロードのマークを押すとインストールされます。 fish
  3. 「Enhanced」または「Premium」と付く声が高品質版で、サイズは100MB〜500MBほどです。 fish
  4. 英語ではZoe（Premium）やEvan（Premium）が、自然な声としておすすめされています。（Ava や Samantha の Enhanced でも構いません） fish
  5. 単語帳アプリを開き直し、「管理」→「発音の設定」で、その声を選びます。「自動」のままでも、点数の高いこれらの声が優先されます。

注意： Siriの声は最も高品質ですが、Webのアプリからは使えません。「Siri」と付く声を入れても、単語帳には反映されません。 readium

Android

  • Androidでは、Google の「音声読み上げエンジン」（Google Text-to-Speech）をPlay Storeからインストールします。多くの機種では最初から入っています。 pongvn
  • 端末の設定で「テキスト読み上げ」を開き、英語（米国）の音声データをダウンロードします。メニュー名は機種によって少し違います。
  • Samsungの端末では、Samsung製の音声エンジンが使われている場合があります。Samsung Internetは、端末に入っているGoogleまたはSamsungの音声エンジンの声を使います。 testmuai

Windows パソコン

  • ブラウザは Edge がおすすめです。EdgeはWindows 11で、Microsoftの自然な声（Natural）を使えます。 testmuai
  • 声が足りない場合は、「設定」→「時刻と言語」→「音声」から追加できます。 pongvn
  • Chromeでも、Google US Englishなどの声が使えます。

Mac

「システム設定」→「アクセシビリティ」→「読み上げコンテンツ」から、Enhanced や Premium の声をダウンロードします（メニュー名はOSのバージョンで少し変わります）。Safari・Chrome・Edgeのどれでも使えます。

気をつけること

  • オンライン音声は通信が必要です。 ChromeのGoogle音声のようなオンラインの声は、文字をブラウザの提供元に送って読み上げます。オフラインで使うなら、端末にダウンロードした音声を選んでください。 pongvn

  • 音声が表示されないときは、アプリを一度閉じて開き直してください。それでも出ない場合は、端末側で音声のダウンロードが終わっているか確認してください。
